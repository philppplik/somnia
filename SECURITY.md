# Security Policy

## Supported versions

Security fixes are released for the latest stable version and the latest pre-release of Somnia. Older versions are not patched. Please update before reporting.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub private vulnerability reporting instead: open the Security tab of this repository and choose "Report a vulnerability" (https://github.com/philppplik/somnia/security/advisories/new).

Please include:

- the Somnia version and operating system
- steps to reproduce, or a proof of concept
- the impact you expect

You can expect a first reply within 7 days. We will keep you updated while we work on a fix and credit you in the release notes if you wish.

## Scope

In scope: the Somnia desktop app, the CLI, the installer, the updater, and the extension store and SDK in this repository.

Out of scope: third-party extensions, social engineering, and findings that need physical access to an unlocked machine.
