Local Agent panel has a collapsed DS PropertyList/Notice/PanelBody disclosure and
native accessible progress bar for AQ's report: used/remaining/overflow text bytes,
output+framing reserve, last-prepared-request label, tokenizer/daemon/image caveats.
Five locales. No approximate current draft made to look like a final request.

Provider computes the aggregate report after its effective output cap and before
its existing byte guard. Observer exceptions cannot bypass enforcement. Bridge
publishes only non-aborted requests to an ephemeral aggregate store. No source
text/tool schema/images/model credentials persist there. Latest tool round replaces
the prior report; invalid/overflow status isn't a proposal or authorization.

UI clears on draft/config/task/target/studio/context-switch changes, stop/reset and
unmount. Unknown before a request or without explicit context stays unknown; zero
remaining is clamped display only, overflow still explicit. Report is last request,
not live prompt tokenization, capacity proof or current document revision evidence.

that remains Unknown rather than fabricating overflow. No inference from opening UI.
