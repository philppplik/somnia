# Local search feedback and keyboard (BB)

Query is a labelled form, Enter submits only a ready/nonempty enabled query.
Keyboard checkbox Space/build Enter/citation Enter use native controls. Existing
cancel/discard remains accessible. Busy section and polite status/error notices.
No whole-result live announcement or raw diagnostic/source leaking in errors.

Five-locale model/runtime unavailable, build failure, query failure and index
not ready/source changed messages describe retry/rebuild paths. They classify the
stage, not precise runtime cause. Selection count and >32 build guard match the
session source bound; no folder/hidden/binary scope expansion or auto network.
No-results copy says no snippets returned, not no relevant evidence. It only
appears after successful empty output, not before search or after failed query.
Ranking currently returns top snippets when a valid nonempty index exists, so
no-results copy is defensive; no relevance threshold or quality claim added.

Validation: 3 added browser cases cover keyboard path, all error stages, five
locales, no auto traffic/model-check source sends and no raw private diagnostics;
light/dark 390px screenshots. Existing 3 AZ browser tests and Agent/provider/
component tests retained. Browser uses synthetic embedding/failure fixtures, not
native/runtime/model downloads, actual screen-reader speech or full app E2E.
Roadmap-Delta: explicit local search feedback/keyboard path, not citation cursor
highlight, folder selection, generated answers or native inference evidence.
