# License inventory review process

Manual CI source-inventory job checks out the exact whisper.cpp revision, CPU-only builds without executing the helper, enumerates real license/notice files with hashes and exact text, captures verbose build/link output, Git source file identities and readelf/dumpbin dependency output. The output is inventory-unreviewed.json plus evidence files, always reviewed false, releaseReady false, empty components and unresolved review work. A source license label or dynamic dependency listing cannot prove complete static/runtime licensing.

Windows uses the runner's existing Visual Studio developer environment/dumpbin; Linux uses readelf. No fetched tooling dependency, invented dependency list, license assignment or approval. No model download or runtime asset publication. Static/vendor/system runtime coverage remains a human review job against verbose build/source/linkage evidence. Build script needs the same build flags; compiler/runner updates can change linkage and need a fresh review.

Reviewer checks source pin, flags, target and source-license/linkage evidence hashes; maps every linked static/dynamic/system component to license and full notice; checks omitted/unknown/vendor components; records reviewer and reviewedAt; removes unresolved items only after investigating them, and sets reviewed true only after sign-off. Put that reviewed record in voice-audits/<target>.json. Preserve evidence hashes in the record. The packaging job verifies reviewer metadata, no unresolved work and exact target/revision before building. It still requires actual linkage review for its current build; source inventory is not the final distribution audit.

No audit is signed off in this slice. CI can now produce real source evidence without pretending missing approvals exist. Helper packaging remains fail-closed until that reviewed record lands. No auto-promotion to voice-releases.json and no isolation/release flags changed.
