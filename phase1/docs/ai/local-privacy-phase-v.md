# What stays on this device

Settings > AI > Local lists task templates, comparison history, task evaluation results, saved offline-only flag and optional helper files/state. Inspection is explicit and each category shows size plus count. Unknown is not empty. No integration/network call, model inference or auto-sync is introduced. This is not a claim that OS/browser backups or all other app data are excluded from sync.

Templates and comparison/evaluation categories use logical UTF-8 JSON payload size, not filesystem allocation. Comparison/evaluation are filtered partitions of one physical bounded history. A delete reads fresh history and writes only the remaining category, preserving the other category and unrelated keys. Corrupt history is Unknown and blocks export/selective deletion rather than silently erasing the other category. Templates can be reset even if corrupt at the utility boundary, but UI intentionally blocks unknown rows. Local exports include private prompts/results; explicit Export writes a local JSON download and warns to keep it private. No cloud link, credential, full preferences file or conversation transcript is exported.

Offline flag is the current saved runtime preference, not an unsaved settings draft. Export includes only that boolean or null. Confirmed delete resets this one flag through the normal save/apply path while preserving other preferences and credentials. The dialog warns that forced offline mode is removed, while existing cloud consent/routing gates still apply. No cloud request or new consent is caused by reset. Busy AI/review/auth state blocks mutations. Refresh other panels after deletes; in-memory results and prior exports/backups remain.

Native helper inventory reports actual file bytes/count under the fixed app-data voice/helpers subtree, bounded by traversal depth/entry count; refuses links and unusual entries. Export is small status-only JSON, never binaries/audio/model. Confirmed remove checks exclusive voice ownership, no active job and fresh subtree validation before removal. Model stays. The status command works without enabling voice preview. Removal of existing files uses the active owner lease or acquires the same exclusive owner lock for this operation, so disabled builds can clean up old files without enabling voice preview. A different owner blocks removal. Absent helper storage needs no owner. Missing files report zero, native unavailable reports Unknown.

Native tests for byte counts, link refusal and owner-lock contention added for CI only. No cargo/WASM run locally. Existing engine/helper preview gates and empty release inventory unchanged. No release artifacts, fabricated checksums/URLs, dependencies or spend.

Roadmap-Delta: explicit local-store inventory, per-category local export, separately confirmed delete/reset, subset-safe shared-history handling, privacy and size boundaries, five locales. Not a full-device data eraser or secure wipe. Native/full app E2E remains CI-only.
