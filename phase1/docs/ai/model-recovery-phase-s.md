# Local model health and recovery

Per-model status combines fresh exact installed tags with an explicitly requested loaded-model snapshot. Includes saved local Agent/task/studio assignments even when missing. Installed, daemon-reported loaded, not installed, unknown inventory/load and unreachable are distinct. This is residency/reachability, not a task-quality or future-inference guarantee. One-click retry rechecks only local metadata, never inference, download or cloud fallback. No background polling.

Offline AI preference is a separate persisted boolean, independent of configured route order. Settings clearly labels draft versus Save. On apply it blocks direct cloud and fallback in renderer privacy gate and native provider transport, preserving route choices instead of erasing/restoring them silently. It does not disconnect networking or block explicit download of local weights/helper. Native Vibe transport observes the same existing local_only gate. In-flight Agent work is cleared by existing settings application; mutation remains disabled during active requests/review.

Pull uses existing per-layer bytes/progress/cancel. Resume/retry button appears after interrupted or failed transfer and reopens explicit review for exactly that model, resets acknowledgement/disk evidence and requires fresh selected-volume preflight. A new Ollama pull may reuse partial daemon layers; there is no guaranteed byte-offset resume or daemon cancel certainty. A100% layer never implies complete installation: native inventory and local-weight verification remain required.

Roadmap-Delta: exact per-model installed/loaded/unknown/unreachable view, safe localized errors/retry, explicit saved offline cloud-blocking preference, review-bound pull retry/resume. No automatic daemon start/download, background monitor, remote inference, quality ranking, physical disk attestation or guaranteed partial-byte reuse.
