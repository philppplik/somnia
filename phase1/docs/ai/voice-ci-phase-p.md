# Voice CI phase P

Manual dispatch only. No PR/push/scheduled triggers and no dispatch performed during development. Standard ubuntu-24.04/windows-2022 hosted runners only, guarded to public repositories so private paid minutes are not consumed. Each job has a timeout. No macOS/larger/self-hosted runner or cloud inference.

Native-contract matrix runs actual Rust voice tests including abrupt parent-crash reexec tests using the same Linux parent-death setup and Windows Job Object used by the runtime. Linux also compiles desktop commands. Failures must remain failures, never continue-on-error or a placeholder pass. Worker subprocesses are inert in ordinary tests unless explicit CI mode is present.

Optional helper build requires the manual build_review_assets input. It fails before downloading if reviewed per-target license inventories are absent. Those inventories are still missing; they must cover actual linkage and cannot be manufactured from engine MIT alone. A reviewer supplies phase1/voice-audits/linux-x86_64.json and windows-x86_64.json before artifacts can be built. Real artifact bytes generate size/hash/notices receipts. No guessed release URLs, signature or release-ready flag.

Linux egress job downloads the actual reviewed helper artifact, explicitly provisions pinned checksum-verified speech weights and synthetic quiet PCM, then runs DE/EN CLI modes in an isolated network namespace under network syscall tracing. A hostile negative-control process attempts IPv4, IPv6, loopback and UDP/DNS-style networking; the trace must detect it. Any IP networking attempted by helper inference fails. Windows uses program-scoped temporary outbound firewall rules and WFP connection/drop auditing, requires a detected hostile negative control, rejects helper network events and restores its audit policy/rules in finally. These are CI test boundaries, not production enforcement. Missing audit privileges or missing evidence fails, never passes unknown.

The PCM fixture is synthetic silence: this exercises language modes but does NOT prove speech accuracy or real microphone behavior. CI helper execution is not the full desktop path. Production egress sandbox, grandchild safety, Windows spawn-assignment race and actual device accuracy remain release gates. No test updates the empty release list or marks isolationProven/orphanCleanupProven true. Native test logs and egress traces/receipts are review evidence, not an automatic release grant.
