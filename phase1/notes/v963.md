# v9.6.3 notes

- **Breadcrumbs:** status bar shows the element path (root to selected element, or to the code cursor when nothing is selected). Click selects that element; Layers, code and design follow. Pure helpers in lib/breadcrumbs.ts.
- **DOM tree:** right rail icon 'DOM tree' opens a collapsible tree of the design file (expand/collapse, search by tag/id/class, selection sync with Layers, code, canvas and breadcrumbs). components/DomTree.tsx.

## Apply formatting
- Command `edit.format` (Alt+Shift+F, editable in Settings > Shortcuts) and a context-menu item. Formats the selection, or the whole file when nothing is selected. One undo step.
- Prettier 3 (MIT) loads lazily, only the plugins the file language needs (HTML, CSS, JS, TS). It is not part of the startup bundle.
- Indentation (2, 4, 8 spaces or tabs) lives in Settings > Code editor.
- Limits: formatting a selection treats it as a standalone snippet; invalid syntax shows a notice and leaves the text untouched.
