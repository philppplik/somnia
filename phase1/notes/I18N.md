# i18n (feature/i18n, alpha)

- Layer: src/lib/i18n.ts (t, translate, resolveLocale), src/lib/useT.ts (React hook). No dependency.
- Catalogues: src/locales/<locale>.json, flat keys, plurals via `_one`/`_other`, placeholders `{name}`.
- Base language is `en` (en-US spelling). Missing keys fall back to en, then to the key.
- Settings > Language: "Follow system" (default) or an explicit language. Stored in localStorage `somnia.locale.v1`.
- To add a language: add src/locales/xx.json, register it in CATALOGUES and LOCALE_NAMES. src/lib/i18n.test.ts then checks missing keys, unused keys and placeholders.
- Non-English catalogues are machine translated; Settings shows a note.
- Migration status: EmptyState, command palette titles (cmd.<id> keys via tOr) and the language setting are done; de is the first machine-translated catalogue. Everything else (Settings body, dialogs, panels, Inspector, canvas menus) is still hardcoded English and moves in tranches.
