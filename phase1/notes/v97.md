# v9.7 notes: Layers drag and drop

- Drag a row in the Layers panel. Drop zone by pointer height: top 30% = before the target, bottom 30% = after, middle = inside (append). A line or ring shows the zone.
- One undoable `move` transaction per drop (same history as source, canvas and code edits).
- Refused with a notice: moving html/head/body, dropping into the element's own descendants, locked layers (not draggable).
- Keyboard alternative: row buttons Move up/down, Indent (into previous sibling) and Outdent (out of parent).
- Logic is pure and unit-tested in lib/layerDrop.ts (planDrop, planIndent, planOutdent); UI wiring in LayersPanel; `moveByPlan` in structureCommands.
- Not yet: dragging on the canvas itself, dragging from the Elements panel into a position, multi-select drag. Planned for v10 (container drop/align).
