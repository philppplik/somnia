# __NAME__

What this extension does, in one or two sentences.

## Permissions

| Permission | Why |
| ---------- | --- |
| commands | Registers the "say hello" command. |
| ui.notify | Shows the greeting. |

## Develop

```
npm run ext -- validate .
npm run ext -- pack .
```

Install the result in Somnia: Settings > Extensions > Add from a .zip package.
