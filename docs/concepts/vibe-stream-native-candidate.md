# Native Vibe streaming candidate, default off

2026-10-14. Candidate implementation, not native-compiled or device-proven in this workspace. No third-party dependencies. `EXPERIMENTAL_OLLAMA_STREAM_ENABLED` is false; desktop wiring does not opt in. Existing tools/cloud/non-Ollama paths remain complete-only. Do not flip the flag until native CI, locality, cancellation and device gates pass.

Experimental ProviderModel text-only path checks fresh local `/api/show` metadata then fixed `/api/chat`, no proxy/redirect/credentials/cloud fallback. NDJSON parser bounds total bytes 256 KiB, line 64 KiB, aggregate text 64 KiB and emits chunks up to 4 KiB. It coalesces at 256 bytes/final, not a timing guarantee. Split UTF-8 is parsed only after a full JSON line. Remote/error/tool-call frames, malformed data, missing terminal success or length finish fail closed. Fixed candidate context 32768/output 2048 plus a 24000-byte text safety bound is not measured token capacity. Model/HTTP errors stay generic, not provider-body disclosure.

ModelTransport gets a default final-only `stream_text` method. Opt-in produces bounded channel text with backpressure. Goose selects cancellation before delta/reply, binds deltas to run/turn/UTF-8 offset, limits frames and checks final text exactly matches emitted provisional text. Provisional text is never a tool effect or model history. Tool-enabled models never opt into this first text-only slice.

Core persists agent.text_delta in the existing event journal before publishing sequenced run_snapshot. Snapshot rebuild enforces offsets/turn identity and replaces provisional text on final agent.message; terminal partial text is assistant_incomplete. Renderer keeps existing sequence, identity, duplicate and stale-read reconciliation rather than a second delta channel. Streaming/incomplete roles have StudioStatus and literal text rendering. Stop/restart has no automatic replay. Existing final-message 6000-character transcript projection remains, not a new full transcript guarantee.

Storage already accepts bounded event payloads, so no database schema migration. Text remains local persisted transcript data, subject to existing retention/export controls. Restart rebuilds partial output as incomplete when crash recovery makes the run terminal; it does not resume inference.

CI-only Rust tests cover split UTF-8, malformed/remote/tool/truncated/size cases and persisted snapshot replacement. Frontend tests cover literal UI and duplicate/stop snapshot reconciliation. Native compilation, actual HTTP opt-in integration, request-drop cancellation, correct persisted stop/restart, packaged desktop and end-to-end device checks remain unverified. Production stays off. No claim of tool-capable streaming or enabled Vibe streaming.
