# Vibe Space task creation hero

New task (Neue Aufgabe) is the single header creation action. It opens the existing Studio form for an exact loaded space, or the space form when none exists. The duplicate New Studio/New space canvas-header actions are removed. The form still explains folder scope, goal, model and Ask for writes before confirmation. Opening never connects a provider, starts a run, grants consent, applies edits or publishes.

Repeated clicks focus the existing form without dropping goal/model/folder drafts. Space switches close the old form; a vanished selected space no longer silently substitutes the first space. Loading/pending/error/capability gates remain authoritative. Browser entry registers disabled commands and displays its native-only explanation without fixture fallback. Needs review and per-run publication remain separate.

Roadmap-Delta: one New task hero promotes existing forms, with no new execution authority.
