# Vector Studio (core)

Vector Studio edits paths and shapes on the existing `src/lib/vectorio` document model (`VectorDocument` with absolute Bezier handles, optional `style`, `layer`, `compound`, `name`, `hidden`). Nothing is parametric: every shape becomes an ordinary editable path. The sibling package `src/components/vectorstudio/tools/` (see `vector-tools.md`) provides the select/node/transform/SVG-IO panels; this package owns the canvas, pointer gestures, session, history and registry integration.

## Public API (`src/lib/vectorstudio/session.ts`)

- Start: `createBlankVector(width, height, name)` (no file needed, size clamped 1 to 16384), `openSvgSource(source, name, {strict})`, `importSvgInto(source)` (appends, one undo step), `resetVectorSession()`.
- Edit: `commit(doc)`, `addPath`, `deleteSelection`, `duplicateSelection`, `moveSelection`, `setStyle`, `setSelectionBounds`, `reorder('front'|'back'|'forward'|'backward')`, `toggleHidden`, `renamePath`, `resizePage`.
- Nodes: `moveNode(pathId, nodeId, point, 'anchor'|'in'|'out')` (smooth and symmetric nodes mirror the opposite handle), `addNodeNear`, `deleteNode`, `setNodeKind`, `toggleClosed`.
- Output: `toSvg()` returns the clean, normalised export (`exportSvg(normalizeDoc(doc))`).
- State: `getVectorSession()`, `subscribeVector`, `useVectorSession`. Fields: `name, doc, selection, tool, zoom, pan, dirty, canUndo, canRedo, diagnostics, error, open, nodePath, selectedNode`.

## Behaviour

- **Blank start.** The empty screen offers Open SVG and Create blank project plus a page size preset (Icon 512, Square 1080, A4, HD, Logo 1024). The same blank project is registered as the app-wide factory for `createBlankProject('vector')` (1024 x 1024).
- **Tools.** Select (V), Node edit (A), Pen (P), Rectangle (R), Ellipse (E), Line (L), Polygon (G), Star (S). A click without a drag places a default-size shape. Drawing a shape returns to Select.
- **Pen.** Click adds a corner node, click and drag adds a smooth node with mirrored handles, a click on the first node closes the path, Enter or double-click finishes an open path, Esc cancels.
- **Compound identity.** All visible contours of a compound are selected, moved, styled, scaled and deleted together. Hidden paths and unknown IDs are excluded from selection, including after commits and history changes. Shift-click toggles the whole object. Appending SVG and duplicating artwork allocate fresh path, node and compound IDs while retaining contour membership, so independent objects never merge during export.
- **Input validation.** `commit` rejects nonfinite page sizes, anchors, handles and numeric style values before changing the document or undo/redo history. Node moves, transforms and view changes also validate their numeric inputs. Invalid coordinates throw `RangeError`; strict import continues to return `false` with diagnostics. Blank creation retains its documented size fallback.
- **Select.** Click, Shift-click toggle, marquee (full containment), drag to move (Shift locks the axis), corner handles scale (Shift keeps the aspect ratio), arrow keys nudge 1 (Shift: 10), Delete, Ctrl/Cmd+D duplicate, Ctrl/Cmd+A select all, Ctrl/Cmd+Z and Y undo and redo. Double-click a path to edit its nodes.
- **Node tool.** Drag anchors and handles, double-click the outline to insert a node without changing the shape, Delete removes the selected node (a path with two nodes is removed as a whole).
- **View.** Ctrl/Cmd+wheel zooms at the cursor, plain wheel and middle or right drag pan, Fit page button.
- **Snapping.** Moving a selection with the Select tool snaps its left/centre/right and top/middle/bottom to the same marks of the page and of other visible paths (6 screen px), with red guide lines while dragging. Hold Alt to move freely. Geometric bounds, no stroke padding; compound members count as separate targets. Not applied to scaling, node drags or shape drawing yet.
- **Drag is one undo step.** Gestures preview from a snapshot and commit once on pointer up. Esc or pointer cancel leaves the document untouched.
- **Dirty work.** Opening or creating a replacement asks for confirmation when the browser session has edits. Cancellation preserves the full session and history; invalid SVG is diagnosed before prompting. Leaving the page invokes the browser unsaved-changes guard. SVG/PNG downloads do not claim that a working file was saved. The global status shows the active Vector name, in-memory state and dirty flag without changing Code project state.
- **SVG.** Opening is strict: unsupported features (foreign text, gradients, images, CSS, clipping, masks, scripts) produce an error plus visible diagnostics and the open document stays unchanged. Export is the shared clean serializer; export then import then export is byte-identical (tested).

## Honest limits

- **Groups.** Group / Ungroup (Transform section) bind two or more objects: clicking one selects all, and they move, scale, align and duplicate together; one undo step each. Members become contiguous at the topmost member's stacking position. SVG: written as `<g data-vs-group="ID">` (inside the layer `<g>` when there is one); other editors just see an ordinary group, and files without the attribute load exactly as before. Layers panel: grouped paths are listed under a Group header (collapse/expand, click selects the whole group, Ungroup button, rename field). Group names are stored as `data-vs-group-name` on the group `<g>` (optional, max 80 chars). Limits: one level only (grouping merges existing groups), no isolated edit mode, group ids on import must be plain (`A-Za-z0-9_.:-`, max 64) or the group is ignored.
- **Gradients.** Style section > Gradient: Linear or Radial fill with start colour, end colour and (linear) angle; command `vector.setGradient` also takes a full `stops` list (2-16). Gradients are document-level (`VectorDocument.gradients`), referenced by `fill="url(#id)"`, and always in objectBoundingBox units, so they follow their object when it moves or scales. SVG: written as `<defs><linearGradient|radialGradient>` with `<stop>`; files without gradients load and export exactly as before (no `<defs>`). Import accepts linear/radial gradients (objectBoundingBox or userSpaceOnUse, `xlink:href` stop inheritance, % offsets, `stop-opacity`) and converts them to box units. Refused on import (strict): `gradientTransform`, `spreadMethod` other than pad, stroke gradients, patterns, missing references. Approximations are reported as warnings: rotated/skewed objects, radial userSpaceOnUse on non-square objects (circle becomes a box-circle), focal points ignored. Unused gradients are dropped on export. Rotating an object does not rotate its gradient; set the angle again.
- **Path operations.** Join paths (two selected open paths; endpoints within 0.5 units merge into one corner node, otherwise a straight segment connects the nearest endpoints; the lower path's style/name wins), Reverse direction (handles swap sides), and Split here (node inspector: an open path splits into two at an inner node, a closed path becomes one open path starting/ending there). Compound contours are refused for join/split; end nodes cannot be split.
- **Offset and outline.** Transform section: "Offset shape" grows (positive) or shrinks (negative) closed shapes by 0.01-500 units with round corners; "Outline stroke" turns a stroke into a filled shape using the drawn width, join (miter/round/bevel, miter limit) and cap (butt/round/square). A closed shape that also has a fill keeps it as a stroke-less shape below the outline. Both flatten curves first, so results are polygonal (an approximation of curves); compound shapes offset with their holes; open shapes can be outlined but not offset; very detailed shapes (> 3000 segments after the band is added) are refused. Dashes are not outlined (the solid stroke is).
- **Round corners.** Transform section: "Round corners" with a radius (0.01-1000) fillets the straight corners of the selected paths with circular-style arcs (cubic approximation). The radius is cut to half of each adjacent side, so it never overshoots. Corners touching a curved segment, open path ends and nodes in a straight line are skipped; the command is refused when nothing could be rounded. Command `vector.roundCorners` also takes `nodeIds` to round only specific corners. Shortcut: Ctrl/Cmd+G groups, Ctrl/Cmd+Shift+G ungroups.
- **Lock.** Layers panel: "Lock"/"Unlock" per path and per group (`vector.toggleLocked {id}`); a compound or group locks as one object. Locked paths cannot be selected (click, marquee, Select all, layer list), so no operation, move or delete can touch them; they stay visible and still export. SVG: `data-vs-locked="1"` on the `<path>`; other editors ignore it, files without it load and export unchanged. Locked state is not an access control, just an editor guard.
- **Simplify.** Transform section: "Simplify" with a tolerance (0.01-100 units) removes nodes that lie within the tolerance of the line between their kept neighbours (Ramer-Douglas-Peucker). Only straight runs are simplified: nodes with handles, curved segments and their end nodes, and the ends of open paths are never touched, so this is for polygons and traced/imported straight paths, not for fitting curves. Refused when nothing could be removed; closed paths keep at least 3 nodes. Command `vector.simplifyPath`.
- **Copy, cut, paste.** Ctrl/Cmd+C, X and V on the canvas. Copy puts the selected objects (with their gradients, groups and group names) on the clipboard as plain SVG text, so they paste into other editors too; cut also deletes them (one undo step). Paste accepts SVG text only, imports it with the same strict rules as opening a file, adds the objects 12 units down-right and selects them (one undo step). The editor never reads the clipboard by itself: it only sees what the browser hands over on a real paste. Other text, or an SVG that fails the strict import, is ignored (the import error is shown). Locked and hidden objects are not copied. No images, no cross-app formats other than SVG text.
- **Rulers and guides.** Rulers run along the top and left edge of the canvas (document units, 1-2-5 steps that follow the zoom). Drag from the top ruler for a horizontal guide, from the left ruler for a vertical one; with the Select tool drag a guide to move it, or drop it on a ruler or outside the canvas to remove it. Dragged selections snap to guides (6 screen px, same as page/object snapping; Alt moves freely). Commands `vector.moveGuide {axis, from?, to?}` (add, move or remove) and `vector.clearGuides` (button in the Page section); at most 100 guides, positions rounded to 0.001. Guides are an editor aid: they are stored as `data-vs-guides="x:10,50;y:20"` on the root `<svg>`, are not drawn by other renderers, and a malformed value is ignored with a warning. They are not applied to scaling, node drags or shape drawing, and there is no unit switch or guide lock.
- **Export area and PNG background.** Export panel: Area = whole page (default, unchanged), Selection or Fit to content, plus a padding (0-1000 units). Cropped exports are cut to the visual bounds (geometry plus half the stroke width; miter joins are padded up to a factor of 4 and square caps by 1.5, so the box may be slightly generous but never clips), moved to the origin, and leave out guides and hidden objects. Locked objects are not part of a selection, so they are not exported by "Selection" but are by "Fit to content". PNG background: transparent (default) or white. Commands `vector.exportSvg {area?, padding?}` and `vector.exportPng {scale?, area?, padding?, background?}`; the old parameter-less calls behave as before. Limit: 16384 units per side for cropped areas (PNG stays capped at 8192 px). No slices, no per-object export, no JPEG/WebP.
- **Clipping masks.** Select two or more objects and press Make clipping mask (Ctrl/Cmd+7; Alt+Ctrl+7 releases). The topmost object becomes the mask: it is not painted and clips the others (commands `vector.makeClip`, `vector.releaseClip`, one undo step each). The Layers panel marks the group "clipped". SVG: `<clipPath>` in `<defs>` plus `clip-path` on the group; on import `clip-path` on a `<g>` or a single shape with a `<clipPath>` holding exactly one shape is accepted (clip-rule kept), the mask is transformed with the referencing element. Marked with `data-vs-group`, so other editors still show the clip. Limits: one mask object, groups do not nest, no `clipPathUnits=objectBoundingBox`, no nested or clipped clipPaths, no opacity masks (`<mask>`). The mask's own style is not painted. Hit-testing and selection bounds still use the unclipped members; Fit to content/Selection export clamp to the mask box. Group, boolean, offset, outline, split and join are refused on a mask until it is released.
- **Copy and paste style.** Transform section: Copy style takes the look of the topmost selected object (fill, stroke, widths, opacities, fill rule, caps, joins, miter limit, dashes); Paste style applies it to the whole selection in one undo step. Shortcuts Alt+Ctrl/Cmd+C and Alt+Ctrl/Cmd+V on the canvas. Commands `vector.copyStyle` and `vector.pasteStyle`. The buffer lives in memory only (not the system clipboard, gone on reload) and holds a snapshot. A gradient fill is only applied when the gradient still exists in the document (otherwise the fill is left as is, the rest is applied). Geometry, groups and layer names are never touched; clip masks are skipped as a source. No eyedropper, no pasting from other apps.
- **Blend mode.** Style section: one blend mode per object (normal, multiply, screen, overlay, darken, lighten, color dodge/burn, hard/soft light, difference, exclusion), set through `vector.setStyle {patch:{blendMode}}`; included in copy/paste style. SVG: `style="mix-blend-mode:multiply"` on the `<path>` (CSS, so other renderers that ignore it show normal blending); the same value is read back on import. Limits: per object only, not per group (a `mix-blend-mode` on an imported `<g>` is refused so nothing is dropped silently); the editor canvas and PNG export use the browser's blending, vector formats other than SVG are not covered; no isolation groups, no opacity masks.
- **Arrowheads.** Style section: "Arrow at start" and "Arrow at end" (none, triangle, open arrow, circle) for open paths with a single contour (lines, pen paths); the selects are disabled for closed or compound shapes. Size is 4x the stroke width, colour follows the stroke when it is a hex colour (otherwise black), included in copy/paste style, `vector.setStyle {patch:{arrowStart, arrowEnd}}`. SVG: the editor writes `<marker data-vs-arrow="triangle">` per kind and colour into `<defs>` and `marker-start`/`marker-end` on the path; only those markers are read back, any other marker, an unknown reference or a marker on a group is refused on import (no silent loss). Limits: no size or offset setting, no per-segment markers, no marker on closed or compound paths, a gradient or named stroke colour gives a black head, boolean/offset/outline results do not carry arrows over.
- **Swatches.** Style section: a colour palette that belongs to the document (up to 64 colours, `#rrggbb`). "Add fill colour"/"Add stroke colour" take the first selected object's colour when it is a plain hex colour (3 or 6 digits; names, alpha and gradients are not added); clicking a swatch applies it as fill or stroke or removes it, as chosen in the select below the chips. Commands `vector.addSwatch {color}`, `vector.removeSwatch {color}`, `vector.applySwatch {color, target:'fill'|'stroke'}` (the colour must be in the palette), each one undo step. SVG: `data-vs-swatches="#ff0000,#00ff00"` on the root `<svg>`; other editors ignore it, a malformed value is ignored with a warning. Limits: a palette is a list of colours, not a link: changing a swatch later does not recolour objects, there is no colour rename, no swatch groups, no global/spot colours, no import of Illustrator/ASE palettes, and the palette is not shared between documents.
- **Text (T).** Live text objects with a system font family, size, normal/bold, normal/italic, left/centre/right alignment, colour (`#rgb`/`#rrggbb`) and multiple lines (max 200 texts, 2000 characters, 50 lines, size 1-1000). A click with the Text tool places one, the Text section edits it (Duplicate text or Ctrl/Cmd+D copies it with a 12 unit offset, `vector.duplicateText`), dragging with Select moves it, Delete removes it; each action is one undo step. Export writes `<text data-vs-text="1">` with one `<tspan>` per line and only those editor-written texts are read back; any other `<text>` (foreign, transforms, CSS, nested markup, inside groups) is still refused. Rotation (-360..360 degrees about the anchor point, SVG `transform="rotate(a x y)"`, only that exact form is read back) and opacity (0-100 %) are set in the Text section or via `vector.setText`; rotation is turned by number, not by a canvas handle, and Fit-to-content export uses the box around the rotated corners. Limits: the font is stored by name and must be installed where the file is opened (nothing is embedded, no outlines); "Load installed fonts" uses the browser's local-font permission and is absent where `queryLocalFonts` does not exist; one font per text object, no rich text, text on path, or boolean operations on text; each text paints either above all shapes (default) or behind all of them (Stacking in the Text section, `vector.setText {back}`; exported as `data-vs-back="1"` written before the shapes) - no interleaving between individual shapes and texts, have no layers-panel entry, are not covered by align/transform (copy, cut and paste work for the selected text through the clipboard SVG, 200-text cap applies), and their bounds are measured in the canvas with an estimate as fallback. Fit-to-content export includes texts, selection export does not. Boolean operations (Combine menu: union, subtract, intersect, exclude) work on closed shapes by flattening curves to polylines, so the result is polygonal (corner nodes) and an approximation of curved input; own implementation (`polyBoolean.ts`), limit 3000 segments, subtract cuts every upper selected shape out of the lowest one, results use the even-odd rule as a compound. Layers are a flat list of paths (`layer` from imported groups is preserved on export).
- Document hit testing shares the tools paint contract, including evenodd/nonzero winding across compound contours, invisible paint and implicit fill closure of open contours. Hit testing flattens curves into polylines; node picking uses screen-constant radii.
- Undo stores document snapshots (200 steps), which is fine for the 10,000 node import limit but not meant for huge artwork.
- PNG export rasterises through an `<img>`; the result is as good as the WebView's SVG renderer.
- `.svg` files still open as text tabs in Code Studio. Vector Studio opens them through Open SVG or the "Edit project SVG" button when an SVG tab is active. Auto-routing `.svg` to this studio is a one-line product decision in `acceptsFormat` usage and was not changed here.
