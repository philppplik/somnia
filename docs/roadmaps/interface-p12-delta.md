# Interface P12 delta: typed component properties and timed transitions

Rebased on fetched `int/beta5` `7c13b003`, stacked on P10/P11 commits pending their integration. Explicit P12 scope, no new dependency, native format, app E2E or production claim.

- Typed component properties join variant axes: text, boolean and instance-swap definitions reference a validated component slot that must exist with a compatible kind in every variant (text layers, any layer for booleans, nested instances for swaps). Values live on the instance (`propertyValues`) and apply only to the materialized copy during synchronization: text replaces layer text, boolean toggles visibility, swap retargets a nested instance to another local component. Unknown names, wrong value types, missing components and swap-driven reference cycles fail validation with rollback. Reset overrides clears typed values too; rename/remove re-key or strip instance values atomically; add-variant value seeding now uses the first variant axis only.
- Prototype interactions v2: links gain an `afterDelay` trigger with an integer 50..60000 ms delay and optional transitions (`instant`, `dissolve`, `smart-animate`; 50..5000 ms for animated kinds; smart-animate is frame-navigation only, never overlays). Preview auto-navigates timed links with cancellation on interaction, and renders animated transitions as display-safe CSS opacity crossfades of frozen frame renders only: no layer matching, no layout interpolation, no runtime app logic; reduced-motion preference skips the crossfade. Authoring documents stay frozen; navigation budget, back/restart and snapshot roundtrip semantics unchanged.
- UI reuses shared controls: interactions panel gains the timed trigger, delay and transition controls with a five-locale display-safe note; variant properties panel gains type and target-layer pickers plus instance text/boolean/swap controls. No token/global CSS or budget change. Thirteenth app acceptance case added (CI-only); actual app E2E remains unrun locally.
