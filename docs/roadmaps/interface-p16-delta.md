Applies cleanly on `3274605d`. No new dependency, native format, no app E2E or production claim.

- Accessibility review: a document-level inspector section audits the frozen resolved scene and lists findings in five locales. Text layers are checked against WCAG AA contrast (4.5:1, 3:1 for large text >=24px or >=18.66px bold) versus the nearest solid ancestor frame fill, with the measured ratio; failing layers suggest up to three local color tokens that pass the threshold against the same background (resolved in the layer's variable mode, best ratio first). Hidden layers are ignored; text on image-filled backgrounds is skipped and counted, never guessed. Interactive layers (prototype links) below 44 x 44 px rendered size get a tap-target warning. Image fills without alt text are flagged, and a matching Alt text inspector field gives the finding a fix path. Findings cap at 200; check counters always run.
- Display-only and undo-neutral: the audit works on an isolated copy; no history, recovery or revision changes. Suggestions are informational text (token name, value, resulting ratio), never applied automatically.
- UI reuses the shared inspector group; labels in five locales. Seventeenth app acceptance case added (CI-only); actual app E2E remains unrun locally.
