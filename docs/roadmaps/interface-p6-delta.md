# Interface P6 delta: local frame links, isolated player and responsive policies

Base fetched/rebased `origin/int/beta5` `1c2d5b5c`. P5 and integration's schema/Field/asset boundary cleanup preserved. This explicit P6 is not the concept's phase numbering or a complete prototype engine.

- Typed local click/hover-to-visible-page-root-frame links, one of each trigger per node, 500-link document cap. Optional explicit flow start. Author controls in the existing Properties panel; no new global studio/rail or Code DOM interaction mapping. Locked/instance-derived structure cannot author links without detach.
- Import validation rejects wrong/missing/hidden/non-root targets, unknown triggers/fields, URLs/scripts and oversized link sets. Cycles are allowed as user navigation, bounded by 100 activations and 50 back entries. Delete target removes inbound links/start in the same undo transaction. Duplicate root frames remap internal targets; frame-local artwork preserves original frame destinations.
- Preview freezes and deep-freezes one validated snapshot, with independent current frame/back/restart state. No authoring session mutations. Instant transitions only, so no animation/reduced-motion discrepancy. Click/tap/Enter/Space, keyboard fallback for hover-only targets, Back/Alt+Left, Restart and Escape/Close. Tab focus trap and return focus; stage gets focus on navigation. Hover requires pointer movement and mouse input, re-arms per frame, no timer-driven automatic navigation.
- Preview pixels use existing local SVG snapshot export, including clipping and bounded image/font diagnostics. Hotspots use computed local geometry and frame clipping, hidden ancestors omit hotspots. Transparent rectangular hit regions are a bounded approximation, not path-accurate hit testing or production app semantics. No arbitrary JS, external URL, delayed action, overlay/scroll-to, interactive component state, dissolve or matched-layer animation.
- Shell context reports preview/read-only; shared Interface command enablement and execution reject document actions during preview. Canvas edit shortcuts do not run while preview is open. UI local edits outside the modal remain authoring workflow, not player runtime; player retains its own frozen source.
- Existing responsive Start/End (pin), Center, Stretch/Scale policies and row/column gap/padding retained. Switching a constraint now rebases current computed child geometry against current parent dimensions, preventing old resize delta from causing a jump. Flow children require absolute positioning before constraints; group edits are atomic/undoable. Existing Hug text approximation and parent Hug/child Fill diagnostics preserved.
- Tests cover isolated state, snapshots/save/reopen, invalid links/budgets, clipping/hidden nodes, cycles/deletion undo, duplicate remapping, shared command read-only gate and responsive rebasing. Existing CI acceptance suite has seven parsed cases including P6 parent resize and frozen preview. Full application acceptance remains CI-only; not run locally.
