# Interface P22 delta

- Prototype/flow polish on top of the existing player:
  - Scroll in preview: a frame can be flagged `scroll` (frames only). The player renders the frame at its full content height inside a clipped, vertically scrollable viewport; children flagged `sticky` hide from the scrolled copy and pin to the viewport top as separate live layers (with their own hotspots).
  - Overlay/modal and drawer presentation: overlay links gain an optional `position` (`center` default modal, or `left`/`right`/`top`/`bottom` drawers). The player places the overlay stage accordingly; the existing dissolve/slide transition animation applies to the overlay stage. Validation keeps position overlay-only and rejects unknown values; switching a link back to navigate clears the position.
  - Hover/pressed state variants: convention-based - when a hotspot is (or sits inside) an instance whose component has a variant named (or propped) `Hover` / `Pressed` (`Active`/`Down` accepted), pointer enter swaps the frozen preview snapshot to that variant, pointer down to pressed, leave restores. No matching variant leaves the preview untouched.
  - Back stack: already existed; P22 pins the behaviour with explicit tests (overlay pops before history, bounded history, restart clears) and carries `overlayPosition` through back/close/restart resets.
  - Shareable local preview export: `exportInterfacePreviewHTML` renders every page-root frame to inline SVG and embeds hotspots, links, scroll/sticky geometry and overlay positions in one self-contained HTML file (40-frame and 8 MB caps). The vanilla runtime needs no network (verified: no external URLs, fetch or imports) and supports navigation, overlays (incl. drawer positions), scroll/sticky, afterDelay timers, back stack, restart, Escape and Alt+Left - transitions degrade to short fades/slides. Player header gains a "Share preview (HTML)" download button (undo-neutral).
- Inspector: `Scroll in preview` checkbox on frames, `Sticky in preview` checkbox on child layers (DS `Checkbox`, no raw controls), `Overlay presentation` select on overlay links - every edit one undo step.
- Preview-only scope: scroll/sticky never touch layout or exports (`exportInterfaceScrollContent` and the sticky/scroll helpers are marked preview-only, mirroring `exportInterfaceLayerSVG`). Five locales via a P22 catalogue; no new dependencies.
