# Interface P10 delta: pages, frame presets and snapshot guides

Rebased on fetched `int/beta5` `7c13b003` with integrated P9 and DS status changes preserved. Explicit P10 scope, no new dependency, native format, app E2E or production claim.

- Generic CSS-pixel Phone 390x844, Tablet 768x1024 and Desktop 1440x900 presets. These are design canvases, not current device hardware specs, safe-area emulation or responsive breakpoint guarantees. Adds top-level fixed-size frame to active page, placed to the right of existing root bounds, finite geometry/32768 limits maintained, undoable. Does not silently resize existing work.
- Page earlier/later reorder controls preserve page identities and selection. Duplicate page inserts adjacent copy, deep-copies settings/unknown page data and artwork with new IDs, remaps internal prototype frame links. Masters copy as ordinary artwork, instances retain document-local component definitions/resources. Empty pages supported, 100-page cap retained. One document transaction per duplicate/reorder, undo/redo; active page selection itself remains session UI state. Undo removing active copy falls back to first surviving page.
- Rulers, smart snap, enabled/grid and explicit X/Y guides are now validated page-local scene fields. Snapshot and recovery persist them; settings edits are dirty/undoable rather than a separate process-global cache. Missing field uses backward-compatible defaults. Settings require boolean enabled/rulers/smart, finite bounded grid and up to 50 guides per axis. Invalid snapshot/transaction rejects without source/recovery replacement. Internal pure snap core avoids validator cycles.
- Existing frozen same-document clipboard works across pages, with destination page IDs/resources/prototype semantics preserved and one undo entry. Cross-document paste still rejects without reviewed resource import; no OS clipboard or unrelated data access. New selection/preset/page-copy reveal waits for rendered nodes on the next animation frame, cleans up pending callback. Pixel verification caught immediate-event reveal before render and it was corrected before delivery.
- Shared Button/NativeSelect controls, localized five-locale labels/generic-size warning, accessible explicit Page select label, no token/global CSS or budget change. Eleven app acceptance cases list-only, P10 maps preset/paste/page duplicate/reorder/snapshot settings; actual app E2E remains CI-only.
