# Interface P13 delta: auto-layout v2 distribution and cross-axis gap

Stacked on the P12 tip plus the delivered GhostImage DS fix (`d3b0caef`); integration tip `83045a96` is not fetchable from origin (fetch still returns `7c13b003`), so this slice patches on top of the local P10-P12 stack. No new dependency, native format, no app E2E or production claim.

- Main-axis distribution: flow layouts (row/column) gain an optional `justify` (`start` default, `center`, `end`, `space-between`). Spare bounded main-axis space is distributed per wrapped line independently, so each line of a wrapping row centers/ends/spaces against its own used width. Overflowing content falls back to start alignment with an explicit diagnostic instead of negative offsets. Fills still consume free space first (water-fill), which leaves justify inert when a fill child exists. Grid keeps its own track sizing and ignores `justify` (documented; the control is hidden for grid).
- Cross-axis gap: `crossGap` separates wrapped lines and grid rows independently of the main-axis `gap` (defaults to `gap` when unset), in placement and in Hug measurement, so a wrapped Hug parent measures its real stacked height.
- Validation closes both fields (`justify` enum, numeric `crossGap`) at import; both roundtrip through snapshots and revert as one undoable transaction. Existing wrap, min/max, absolute-child, per-side padding and free-layout constraint behavior is unchanged.
- UI reuses shared controls: the layout inspector gains a Distribution select (Start/Center/End/Space between, hidden for grid) and a Cross gap number field shown for wrapped or grid layouts, with five-locale labels. No token/global CSS, no inline-style budget change. Fourteenth app acceptance case added (CI-only); actual app E2E remains unrun locally.

Verification: 228 owned Interface/studio/shell tests including per-line distribution, overflow fallback diagnostics, crossGap placement and Hug measure, closed validation, roundtrip and undo/redo; panels render coverage in English and German.
