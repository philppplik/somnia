# Interface P32 delta — prototyping polish

Base: P31 commit (stacked; P31 not yet upstream at build time). Scope check first: click/hover/after-delay triggers, navigate/overlay actions with overlay positioning, five transition kinds with duration/easing/direction plus one-click presets, conditions with else targets, variable setters, and the interactive play-mode preview (hotspots, overlays, scroll/sticky, state variants, transitions, back/restart, shareable offline HTML) all already existed and were kept. Two genuine gaps were built:

1. **Press trigger**: links can now fire on pointer down (`trigger:'press'`) alongside click/hover/after-delay. The preview player activates press links from the hotspot pointer-down (mouse only, alongside the pressed state variant), the share-preview HTML runtime fires them on mousedown, hotspots expose a dedicated press flag, and the per-layer link budget rises from two to three so press can coexist with existing links. Editing is a new row in the Frame links panel, one undo per change via session transacts.
2. **Back action**: a link can now walk the preview history (`action:'back'`) instead of targeting a frame. Back links carry an empty target (validated: any frame target is rejected), close an open overlay first like the Back button, apply variable setters and respect conditions, report instead of navigating with an empty history, and play their configured transition on the way back. The share-preview runtime walks its history stack the same way.

Tests: 337 focused tests green (+6: 5 lib tests, 1 EN/DE render test). Gates: check:ds, check:ui-commands, check:commands, check:layers all pass; tsc clean apart from known upstream studio3d/slides/stage noise. CI-only spec `Interface P32 press trigger navigates on pointer down and the back action returns with one undo each` added; acceptance paragraph P32 added.
