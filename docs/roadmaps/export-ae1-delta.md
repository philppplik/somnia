# AE1 Delta - Shared Advanced Export dialog, Photos zuerst

- Shared Schema-Lib (src/lib/export/): deklarative ExportField/ExportSchema-Typen (select/text/number/range/checkbox, Gruppen, visibleWhen, Cross-Field-Validierung), lokale Presets pro Studio (localStorage, max. 20), Dimensionen-Mathe (Prozent/exakt, Aspect-Lock, Clamp 1..16384px/16MP) und dependency-freie Metadaten-Injection (PNG tEXt, JPEG COM, mit Round-Trip-Readern).
- Shared Dialog (src/components/export/AdvancedExportDialog.tsx): rendert jedes Studio-Schema mit DS-Primitives (Dialog/Input/NumberField/RangeField/Checkbox/NativeSelect/Button), Live-Vorschau + exakte Endgroesse aus dem Proberendern (debounced), Preset-UI; --no-bloat: Metadaten und Presets sind eingeklappt; max-h + Scroll fuer kleine Viewports; i18n x5.
- Photos-Verdrahtung: photos.export.advanced Command (Options-Bag, alte Commands unveraendert), exportPhotoCopyAdvanced/renderPhotoExportPreview in studioSession (Engine-PNG -> Canvas-Pipeline: Skalierung, webp/jpeg/png, Qualitaet, Graustufen, Display-P3 wo unterstuetzt, Metadaten), ersetzt den alten 2-Optionen-Popover; oeffentliche Hooks photos-export-popover/-format bleiben (Host-Passthrough).
- Tests: 9 Unit-Tests (Schema/Dimensionen/Metadaten/Photos-Optionen), CI-Spec "Photos AE1 advanced export" (Format/Qualitaet/Metadaten/Dateiname + Download-Bytes), isolierte Pixel-Fixture test/export-preview.html (hell EN + dunkel DE geprueft: Vorschau, Endgroesse PNG 289KB -> JPEG 10KB, Export sample-photo.jpg).
- Kein neues Third-Party-Dependency, keine tokens.css/global.css-Aenderung, DS-Budgets unveraendert (neuer Bereich src/components/export: 0 raw controls/inline styles). check:ds/check:commands gruen bis auf bereits am Upstream-Tip bestehende Befunde (SoundRack raw select, cmd.photos.applyVersion ohne Titel) - nicht von AE1.
