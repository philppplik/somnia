# Local lexical references

Tools > navigation > Find local references (`Shift+F12`) opens a read-only dialog from the current canonical source editor selection. Each row has a bounded source-line preview, one-based line/UTF-16 column and declaration/reference label. Click a row to reveal its exact identifier span in the existing editor. This is not project-wide Find All References or a language server, and does not use name matching as evidence of a binding.

The implementation uses the existing local-definition resolver for every same-spelled variable identifier. Only identifiers resolving to the target's exact declaration span enter the list. Shadowed names, comments, strings and ordinary property names are not references. Declaration is included and the count says so. Unsupported files fail as a whole, rather than returning a plausible partial list.

Limits: JS/TS language modes, 32k source characters, at most 160 variable identifiers and the existing resolver's bounded parser/construct restrictions. Imports/exports, classes, destructuring, `var`, loops/catch, eval, JSX, shorthand properties and type-name nodes are refused. Simple supported functions, parameters, lexical declarations and closures work. This reuses the small local lexical resolver, not a general compiler; it does not add a worker or a hard execution timeout. Large files get an explicit no-partial-list message. Previews retain at most 60 characters before and 100 after the identifier, with ellipses.

Before opening, the active editor must be connected, Code Studio active and editor source exactly equal to canonical source. Before jumping, owner adapter, editor instance, project generation, active file and source are rechecked. The captured selection's references are rebuilt and the clicked row must match a fresh result exactly. Changed selection alone does not retarget the opened list; changed source/project/file/editor rejects the old row. Dialog/unrelated input shortcuts cannot open a second reference dialog. Agent/MCP origins cannot execute this UI command. No source transaction, save, undo entry, filesystem access or remote request is added.

The existing dialog and symbol-row DS components/styles are reused; no permanent panel, toolbar button or dependency. Titles and status/limits are translated in all five catalogue languages. The command appears in the existing navigation group and inventory.

Focused tests cover lexical identity/shadowing, comments/string/property lookalikes, closures/parameters, Unicode positions and bounded previews, unsupported/malformed source and limits, command schema/origin/group/i18n. Browser tests cover Light/Dark rendering, keyboard invocation, exact-span reveal without edits, source/project drift, forged rows, editor/canonical mismatch and unrelated dialog inputs, plus the unchanged F12 tests. Native/WASM and full packaged desktop remain CI-only.
