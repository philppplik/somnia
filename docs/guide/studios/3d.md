# 3D Studio

Status: **In development.** Built on the `int/beta5` integration branch. It is not in a published release (latest pre-release is v12.2.0-beta.4). Features can change before it ships. This page lists only what is merged on `int/beta5` as of 2026-10-14.

## Opens

- glTF and GLB files. Smart open routes `.glb` and `.gltf` here.
- OBJ (with MTL textures), STL and PLY import.
- `.som3d` scene documents (format version 1, saved by this studio).

The studio needs no network. Models are not fetched on import.

## Start

Choose 3D in the studio pill and start blank, or open a model. Insert parametric primitives (shapes with numeric sizes), lights and cameras from the Scene panel.

## Scene and objects

- Scene panel: outliner with show/hide and lock, drag to reparent, Ctrl and Shift multi-select, inline rename, `F` to frame the selection.
- Move, rotate and scale gizmos with undo grouping. Numeric transforms, relative numeric entry, pivot and a 3D cursor.
- Snapping (move, rotate, scale steps and a midpoint snap with hotkeys), align and distribute, groups and arrays.
- Measure tool for distances.
- Named views, orthographic and perspective cameras, view presets.

## Materials and lighting

- PBR materials with texture slots, glass and wood presets, a metal texture slot, copy and paste of materials, and editable local material presets you can save, apply and remove.
- Directional, point, spot and area lights, ambient lights, light shadows, and a three-point light rig preset.
- HDRI environments, outdoor and dark presets, background modes, and custom HDR/EXR maps. A map can be embedded in the scene, up to 16 MB.

## Modelling

- Mesh edit mode with edge bevel (round profile), loop slide, mirror modifier and mirror bisect.
- Sculpt brushes with masking and a mask colour overlay.
- UV tools: seams, box and planar unwrap, angle-based unwrap, island packing, a checker preview and an island view.

## Rigs and animation

- Skeleton import with a bone overlay, click-select for bones and a rotate-only gizmo.
- Skinning: auto-weights, weight preview, a weight paint brush with a bind-pose guard, rigid re-bind.
- Poses: a pose library with mirror and blend, recording keyframes at the playhead for selected or all bones.
- IK: two-bone IK with pole vector and joint limits, FK/IK toggle, FABRIK for chains of N bones with a look-at constraint.
- Animation clips: a visual clip timeline with keys, per-key easing, auto-key, zoom and pan, multi-select, copy and paste, clip duplicate and a loop range. Onion skin, motion path and retargeting between rigs.

## Save and export

| Output | Notes |
| --- | --- |
| `.som3d` | JSON document. The geometry is a standard GLB inside it (embedded, or a sidecar GLB next to it). Versioned. [Format](../../concepts/3d-studio-document.md) |
| GLB / glTF | Export options and scene budget warnings. Clips and skins round-trip. Selection-only export. |
| OBJ, STL | Export uses the project unit. glTF is always metres. |
| PNG still | The header action is **Render** (still image from the current camera). |
| Turntable | Folder or ZIP of frames. |

Autosave and recent scenes are kept in the app's browser storage: at most 6 scenes and one autosave slot, 48 MB per scene. Save a `.som3d` file to keep your work. **Ctrl/Cmd+S** saves.

## Limits

- Animations and skins are whatever the GLB exporter writes.
- Scene checks warn about budgets; they do not guarantee another engine will render the model the same way.
- The studio manifest registers no dedicated shortcut.
- Local AI can write a reviewable session note describing bounded scene metadata. The note is not saved in the scene or in GLB or `.som3d` exports. See [Local AI](../local-ai.md).
