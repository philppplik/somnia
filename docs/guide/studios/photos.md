# Photos Studio

Status: check the release notes of your version. The hero action state is in [Hero actions](../hero-actions.md).

## Opens

Raster images (PNG, JPEG and others).

## Blank start

Opens an empty start screen. Open an image to edit. Blank documents live in memory until you save them.

## Rail and panels

Files, Develop. Panels: histogram, light, color, effects, detail, transform, presets, export, and a history panel (50 steps).

## Header action

Export. Opens an export popover. Menu: PNG, JPEG.

## Export and save

PNG or JPEG copy. Limits are shown in the export panel.

## Limits

- Edits are non-destructive. The histogram is measured on a preview up to 1024 px, not the original.
- Crop presets: free, original, 1:1, 4:3, 3:2, 16:9, 5:4, 3:4, 2:3, 9:16.
