# Vibe Space

Status: check the release notes of your version. The hero action state is in [Hero actions](../hero-actions.md).

## Opens

Spaces and studio runs of autonomous agents.

## Blank start

Create a space, then a studio inside it. Blank documents live in memory until you save them.

## Rail and panels

Vibe Spaces, Studio runs, Needs review, Memory, Skills, plus a Vibe Space inspector.

## Header action

New task. It opens the Studio creation form for the selected space. The label was decided on 2026-10-13; the concept first proposed "New Studio...".

## Export and save

Not applicable.

## Limits

- The Rust core owns runs, consent, isolation, metering and persistence. The UI shows them and sends explicit user actions.
- Agents work under a policy and need your review where the policy says so. Read the policy before you start a run.
