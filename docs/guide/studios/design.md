# Design Studio

Status: check the release notes of your version. The hero action state is in [Hero actions](../hero-actions.md).

## Opens

Design projects with artboards (rectangle, text and frame layers). JSON project import and export.

## Blank start

One valid artboard with no layers. Blank documents live in memory until you save them.

## Rail and panels

Files, plus Artboard and layers.

## Header action

Export. Opens the export popover for the active artboard.

## Export and save

SVG export and project export (.somdesign).

## Limits

- Tools: select, hand, rectangle, text, frame. History, selection, move and resize are supported.
