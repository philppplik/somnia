# Documents Studio

Status: check the release notes of your version. The hero action state is in [Hero actions](../hero-actions.md).

## Opens

Word documents (.docx).

## Blank start

A4 document with one empty paragraph. Blank documents live in memory until you save them.

## Rail and panels

Files, Pages, Outline, Find, Search, Versions, plus a Document inspector.

## Header action

Export, with a real .docx save copy first. PDF appears only after a verified export path exists.

## Export and save

Save a copy as .docx. The original file is not overwritten by export.

## Limits

- Editing is on the page with a caret. Check layout in Word for complex documents.
