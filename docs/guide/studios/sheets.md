# Sheets Studio

Status: check the release notes of your version. The hero action state is in [Hero actions](../hero-actions.md).

## Opens

Spreadsheets (.xlsx).

## Blank start

Workbook with one empty worksheet. Blank documents live in memory until you save them.

## Rail and panels

Files, Search, Versions, plus workbook, analysis and inspector panels.

## Header action

Smart Formula. Opens the formula builder seeded from the selected range. It is a local helper, not a cloud AI prompt, and does not write a cell on the first click.

## Export and save

Export a copy as .xlsx.

## Limits

- Cell and formula editing follow the existing sheet engine. Check results against your own spreadsheet app before you rely on them.
