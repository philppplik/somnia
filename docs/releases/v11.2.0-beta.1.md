# Somnia v11.2.0-beta.1

## Highlights
- Direct OpenAI API and Anthropic Claude API providers, alongside Ollama and OpenRouter.
- Explicit model catalog refresh and manual model IDs.
- Provider connection controls: metadata-only key test, save/rotate, local delete, cancel and visible errors.
- Smoother token rendering, clear stopped/interrupted partial answers, explicit Retry.

## Fixes
- Separate OS credential slots; selecting Ollama does not delete a saved cloud key.
- Saved desktop keys no longer return to the editor WebView. The Rust transport resolves keys and uses fixed provider endpoints.
- Bounded pre-stream retries, Retry-After handling, quota/rate-limit distinction and no automatic retry after output begins.
- Provider switch/configuration changes start a fresh chat. Existing custom prompts stay local and are sent only when enabled.
- Retains the macOS ad-hoc signature fix and CI DMG verification from 11.1.1-beta.1.

## Known issues
- Claude supports text and client tool calls; thinking/server-tool blocks are rejected. OpenAI uses Chat Completions, not the future Responses adapter. Model catalog membership does not guarantee tool support or available credits.
- BYOK API access only. No Claude.ai or ChatGPT subscription login. API usage may cost money; no live paid inference was used to test this beta.
- Native transport has fixed endpoints, no custom proxy, 120-second total/30-second idle timeouts. A pre-header abort is bounded by timeout, not instantaneous. Existing global cloud consent is still application-level.
- Windows/macOS interactive launch and real OS credential-store unlock/restart tests are unverified. Native provider HTTPS streaming with a real account is also unverified.
- macOS is Apple Silicon only, ad-hoc signed and not notarized. Gatekeeper may require System Settings > Privacy & Security > Open Anyway. Do not disable Gatekeeper.
- Collaboration remains alpha; LAN, relay, updater installs and real provider/model quality are not certified by offline tests.

## Install
- Windows: setup.exe/MSI. Linux: AppImage/DEB. macOS: DMG, copy to Applications, follow the security exception above if offered.
- This prerelease does not replace stable v11.1.0 or the Microsoft Store package.
