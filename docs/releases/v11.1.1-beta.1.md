# Somnia v11.1.1-beta.1

## Highlights
- Agent: remember provider/model locally and API key in the OS credential store. No plaintext key fallback.
- Agent: create, edit, delete and enable custom prompts, persisted locally and included in every AI provider request. Cloud consent and file access approval remain separate.

- macOS packaging fix: explicitly ad-hoc sign the complete app bundle. Previously the macOS build did not configure a signing identity.

## Fixes
- Bind Info.plist and seal app resources instead of relying on the compiler/linker signature on Apple Silicon.
- CI now checks DMG integrity using hdiutil, strict codesign verification of the app inside the DMG and the updater archive, and records Gatekeeper assessment.

## Known issues
- This is an ad-hoc signed beta, not Developer-ID signed or notarized. Gatekeeper will still reject automatic trust. A warning-free first launch needs an Apple Developer ID certificate and notarization.
- On macOS, copy Somnia to Applications, try opening it, then use System Settings > Privacy & Security > Open Anyway if macOS offers that option. Do not disable Gatekeeper. See https://support.apple.com/en-us/102445 . If macOS still says damaged, report the exact dialog and macOS version; successful launch on the maintainer Mac is not yet verified.
- Windows and macOS interactive acceptance tests have not been run here. macOS CI signature/image checks do not prove the downloaded, quarantined app launches on every Mac.
- Collaboration is alpha, tested with two windows in CI only. LAN, relay, real Windows/macOS use, updater installation, and real Ollama/OpenRouter use remain unverified.
- Existing beta.6 limitations remain, including the LaTeX write18 reporting quirk and session avatar overwrite behavior.

## Install
- Download the DMG for Apple Silicon (arm64). This release does not add an Intel macOS build.
- Windows: setup.exe or MSI. Linux: AppImage or DEB.
- This prerelease does not replace the stable v11.1.0 updater channel or the Microsoft Store package.
