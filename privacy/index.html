Somnia / Privacy policy

Privacy policy.

What Somnia does with your data, in plain words. Short answer: it stays on your computer.

Short version. Somnia works on files on your own computer. It has no account, no analytics and no tracking, and the developer does not receive your files or any data about how you use the app. The app makes network requests only for things you choose: the update check, an AI provider you turn on, and collaboration hosts you set up.

Last updated: October 17, 2026. Somnia is in beta. This page describes the app as it is built today, and it will change when the app does.

Who is responsible

Somnia is developed by Philipp Paulik (the "developer"). Contact for privacy questions: philipp.l.paulik@gmail.com.

Your files stay on your device

Somnia opens a folder or file that you choose and saves changes back to the same place on your disk. Your files are not uploaded to the developer. The developer has no server that receives them.

Data stored locally by the app

Recovery snapshots. While you edit, the app keeps unsaved changes in a local recovery folder inside the app data folder of your user profile, so work can be restored after a crash. A snapshot is removed after you save the file.

Settings and saved items. Layout, theme, keyboard shortcuts, your saved component library and your extension choices are kept in the app's local storage on your device. If you use the AI panel, the chosen provider, the model name, your custom prompts and your cloud consent record (version and time) are stored on your device too.

API keys. If you add an API key for an AI provider, the desktop app stores it in your operating system's credential store, not in a plain settings file.

None of this is sent to the developer. To remove it, delete your project folders and uninstall the app. Uninstalling removes the program files. The local app data folder can be deleted by hand if you also want to remove recovery snapshots and settings.

No accounts, no analytics, no tracking

Somnia has no sign-in, no telemetry, no crash reporting, no advertising and no third-party analytics. The developer does not collect personal data about you through the app.

Update check

When the app starts, it can ask GitHub whether a newer release exists by requesting the public release list of github.com/philppplik/somnia from api.github.com. The request carries no account, no project data and no identifier from the app. As with any web request, GitHub receives your IP address and standard technical request data, and handles it under the GitHub Privacy Statement. You can turn this check off in Settings. If you choose to install an update, the app downloads it from GitHub the same way.

If you install Somnia from the Microsoft Store, the Microsoft Store handles app updates and its own data collection under the Microsoft Privacy Statement. The developer does not receive that data.

Somnia Agent and AI services (optional, beta)

The AI panel is optional and still in beta. It uses artificial intelligence to answer prompts and propose changes. AI can make mistakes. Check generated content and review changes before you apply or publish them. AI responses and suggested changes are labelled in the app.

You bring your own provider. The panel can connect to OpenRouter, OpenAI, Claude (Anthropic) and Ollama. Nothing is sent to any of them until you set one up.

Cloud providers. Before the first cloud request, Somnia asks you to explicitly allow sending your prompt, relevant conversation context and selected project content to the provider you choose. This applies to OpenRouter, OpenAI and Claude, and to any Ollama server that is not on your own machine. OpenRouter may route your content to its own model providers. Processing may take place outside the EU. Retention, training, deletion and transfer practices differ by service, account type and settings, and they are the provider's, not Somnia's. A ChatGPT or Claude subscription does not mean processing stays local. Read your provider's privacy information:

  • OpenAI
  • Anthropic Privacy Center
  • OpenRouter, and its data collection guidance

Review the context before sending. Do not include passwords, API keys or personal data you do not have permission to share. Your opt-in does not give you permission to disclose another person's data.

Withdrawing consent. You can withdraw cloud consent in Settings under AI privacy. Withdrawal blocks new cloud requests and cancels active ones in Somnia. It does not erase content a provider has already received, and it does not guarantee the provider stops processing it. Contact the provider for its processing. You can keep using the editor without cloud AI. Deleting a saved key in the app removes Somnia's copy only. It does not revoke the key at the provider.

Local processing. You can use Ollama on your own device with a local model. Somnia treats a local Ollama server as local only when it runs on your machine and reports local model weights. A local server may have its own logging settings.

Collaboration

Real-time collaboration is optional and starts only when you start or join a session. Sessions run through a host you choose: a host on your own computer or local network, or a relay you run yourself. The developer does not operate a collaboration server for you. Content is end-to-end encrypted by the apps, and the relay forwards encrypted data without storing it. The host you choose and the people you invite can see what you share in the session. Your IP address is visible to the host and to peers, as with any network connection.

Preview and extensions

The live preview runs in an isolated frame that has no network access. Scripts from your project run in it only after you allow that for a project. Extensions run locally in a restricted worker with a declared set of permissions, and network access is removed from them on a best-effort basis. That is a safeguard, not a guarantee.

This website

This site (somnia.philipp-paulik.de) is a static site hosted on GitHub Pages. It does not use cookies, analytics or third-party scripts. The download section requests the public release list from api.github.com in your browser, so GitHub receives your IP address as described above. GitHub, as the host, may also process technical data such as your IP address in server logs.

Your rights

Because the developer does not collect personal data through the app, there is normally nothing to access, correct or delete on his side. If you are in the EU or UK and think the developer holds data about you, write to the address above and you will get an answer. You also have the right to complain to your local data protection authority. For data that an AI provider, GitHub or Microsoft processes, contact that company.

Children

Somnia is a general-purpose creative tool and is not directed at children. The developer does not collect data from anyone through it.

Changes

If the app starts to handle data differently, this page will be updated before that release and the change will be listed here. The current version is always at somnia.philipp-paulik.de/privacy/. A German version is at /datenschutz/.
